### CHINOOK DATABSE

Esta base de datos interconectada nos presenta datos sobre una empresa de ventas de discos de música - compuesta de varias tiendas fisicas. 
Està interconectada ya que tenemos varias tablas compuestas alugunas de un 'Primary Key' y otras de un 'Foreign Key', con lo cual, algunos datos de ventas permiten obtener información sobre otros datos vinculados a aquellas ventas como por ejemplo el/la emplead@ que ha realizado la venta, tal y como el cliente quien hizo adqusicion del producto/disco.
